## Ключевые концепции для экзамена

| Концепция | Описание |
|-----------|----------|
| **Declarative** | Описываем ЧТО хотим получить, а не КАК |
| **Idempotent** | Многократное применение даёт одинаковый результат |
| **Immutable** | Изменения создают новые ресурсы вместо модификации |
| **State** | Terraform хранит состояние инфраструктуры |
