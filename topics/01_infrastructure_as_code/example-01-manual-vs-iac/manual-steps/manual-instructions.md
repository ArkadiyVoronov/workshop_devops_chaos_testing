# Manual Steps Documentation

Этот файл демонстрирует, как бы выглядело создание инфраструктуры вручную.

## Сценарий: Создание веб-сервера с базой данных

### Шаг 1: Создать виртуальную машину
1. Зайти в консоль облачного провайдера
2. Перейти в раздел "Virtual Machines"
3. Нажать "Create VM"
4. Выбрать образ Ubuntu 22.04
5. Выбрать размер: 2 vCPU, 4GB RAM
6. Настроить диск: 50GB SSD
7. Нажать "Create"

### Шаг 2: Настроить группу безопасности
1. Перейти в "Security Groups"
2. Создать новую группу "web-sg"
3. Добавить правила:
   - Port 80 (HTTP) - открыт для 0.0.0.0/0
   - Port 443 (HTTPS) - открыт для 0.0.0.0/0
   - Port 22 (SSH) - открыт для офиса
4. Применить группу к VM из шага 1

### Шаг 3: Создать базу данных
1. Перейти в "Databases"
2. Выбрать "Create Database"
3. Выбрать тип: PostgreSQL 14
4. Настроить параметры: 2 vCPU, 8GB RAM, 100GB storage
5. Настроить бэкапы: daily, retention 7 days
6. Нажать "Create"

### Шаг 4: Создать хранилище
1. Перейти в "Storage Accounts"
2. Создать новый storage account
3. Выбрать тип: Standard LRS
4. Создать контейнер "app-data"

## Проблемы этого подхода

| Проблема | Описание |
|----------|----------|
| **Нет версионирования** | Неизвестно, кто и когда менял настройки |
| **Человеческий фактор** | Можно забыть шаг или выбрать wrong параметры |
| **Сложность воспроизведения** | Другой человек создаст инфраструктуру иначе |
| **Неидемпотентность** | Повторение шагов создаст дубликаты ресурсов |
| **Время** | Ручное создание занимает 30-60 минут |

## Сравнение с Terraform

```bash
# Terraform делает всё это одной командой:
terraform apply

# Время выполнения: 2-3 минуты
# Результат: идентичный при каждом запуске
# Откат: terraform destroy или revert commit
```
