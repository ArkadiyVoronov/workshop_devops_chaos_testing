## Ключевые концепции для экзамена

### 1. Синтаксис HCL
- Блоки: `resource "type" "name" { }`
- Аргументы: `key = value`
- Комментарии: `#` или `//`

### 2. Основные блоки
- `terraform` - настройки Terraform
- `provider` - подключение к облачным платформам
- `resource` - определение инфраструктуры
- `data` - чтение существующих ресурсов
- `variable` - входные параметры
- `output` - выходные значения
- `locals` - локальные переменные

### 3. State файл
- Хранит текущее состояние инфраструктуры
- Формат JSON
- Локальный (`terraform.tfstate`) или удаленный бекенд
